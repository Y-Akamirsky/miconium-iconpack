# Структура икон-пака Miconium

**Пак** — это обычная директория SVG-слоёв, из которых Miconium собирает
целую тему иконок. Пак — это чистые данные: без сборки, без бинарного
формата. Если вы умеете редактировать SVG — вы умеете делать пак.

```
<имя-пака>/
├── accessories/              (опционально)
├── frames/
│   ├── colorizable/          обязательно — перекрашиваемые подложки
│   └── static/               опционально — подложки для светлой/тёмной темы
│       ├── Dark/
│       └── Light/
└── signs/
    ├── apps/
    ├── categories/
    ├── devices/
    ├── emblems/
    ├── mimetypes/
    ├── places/
    ├── preferences/
    └── status/
```

## `frames/`

Фоновая подложка, которая рисуется под значком.

- **`frames/colorizable/`** (обязательно) — подложки, цвета которых Miconium
  перекрашивает при генерации. Это основной источник перекрашиваемых подложек.
- **`frames/static/Dark/`, `frames/static/Light/`** (опционально) — подложки,
  которые автоматически выбираются для тёмной или светлой схемы. Используйте
  их, когда подложке нужны фиксированные цвета (например, градиент или
  контур с заданным контрастом).

## `signs/`

Собственно глифы, сгруппированные по категориям. Набор категорий свободный;
перечисленные выше — те, которые ожидает раскладка вывода Miconium.

Внутри категории может быть:

- **просто `*.svg` файлы** — вариант по умолчанию (считается `scalable`), либо
- **поддиректории-варианты** — именованные варианты: `scalable`, `symbolic`,
  `16`, `22`, `scalable-outlined`.

```
signs/apps/
├── scalable/          ← именованный вариант
│   ├── firefox.svg
│   └── ...
├── symbolic/          ← именованный вариант
│   └── ...
└── gimp.svg           ← вариант по умолчанию (без поддиректории)
```

Варианты — это то, что позволяет одному паку быть полезным на разных
размерах и в разных стилях: `symbolic` для панелей и меню, `16` для мелких
элементов интерфейса и так далее. Какой вариант использовать в категории,
выбирает пользователь (или GUI).

## `accessories/` (опционально)

Декоративные накладки, которые рисуются поверх подложки: блики, градиенты,
рамки, «печеньки» на углах и прочие украшения. Цвета перекрашиваются при
генерации, каждое украшение можно позиционировать, вращать и масштабировать.

## Цвета

Подложки, значки и украшения получают цвета из активной палитры: `background`,
`foreground` и `accent` соответственно (соответствие настраивается в пресете).
Чтобы слой перекрашивался, задайте его фигурам placeholder-цвета, которые
Miconium подменяет — см. пресет или `miconium.example.toml` в репозитории
программы.

## Проверка пака

В комплекте есть валидатор — нужен только bash:

```bash
./validate.sh            # проверяет все паки в репозитории
./validate.sh my-pack    # проверяет один пак
```

Он проверяет обязательные директории, что в каждой категории действительно
есть слои, что все SVG читаются, не пустые и содержат корень `<svg>`, и
печатает сводку по категориям. Код возврата `0` означает, что Miconium сможет
загрузить пак.

## Установка своего пака

Miconium находит паки по имени, поэтому имя директории — это имя пака.

- **Системно:** установите в `/usr/share/miconium/<имя-пака>/` — именно это
  делают `make install` и `PKGBUILD` этого репозитория.
- **Для пользователя:** скопируйте в `~/.local/share/miconium/<имя-пака>/`.

Затем выберите пак в GUI Miconium или укажите его в конфиге/пресете:

```toml
[pack]
name = "my-pack"
```

Если хотите распространять свой пак, создайте свой репозиторий по образцу
этого — достаточно структуры и валидатора.
